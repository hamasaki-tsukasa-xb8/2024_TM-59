# パラメータの設定

- **epsilon** (ε-greedy戦略の探索率)  
**意味**: epsilon は、エージェントがランダムに行動を選択する確率を示します。epsilon が高いほど、エージェントは探索を多く行い、ランダムに行動を選択します。逆に、epsilon が低いほど、エージェントは既存の知識（Qテーブル）に基づいて行動を選択します。  
**変更の影響**:  
高い epsilon 値 (例: 0.9): エージェントは多くの探索を行い、未知の状態や行動を試すことが多くなります。初期段階での探索が重要な場合に有効です。  
低い epsilon 値 (例: 0.1): エージェントは既存の知識に基づいて行動を選択することが多くなります。学習が進んで最適な行動が見つかっている場合に有効です。  

- gamma (割引率)  
**意味**: gamma は、将来の報酬の現在価値をどの程度考慮するかを示します。gamma が高いほど、将来の報酬を重視します。逆に、gamma が低いほど、即時の報酬を重視します。  
**変更の影響**:  
高い gamma 値 (例: 0.9): エージェントは長期的な報酬を重視し、将来の利益を考慮して行動を選択します。長期的な戦略が重要な場合に有効です。  
低い gamma 値 (例: 0.1): エージェントは即時の報酬を重視し、短期的な利益を優先します。短期的な成果が重要な場合に有効です。  

- alpha (学習率)  
**意味**: alpha は、Q値の更新において新しい情報をどの程度反映させるかを示します。alpha が高いほど、新しい情報を強く反映します。逆に、alpha が低いほど、既存の知識を重視します。  
**変更の影響**:  
高い alpha 値 (例: 0.9): エージェントは新しい経験を強く反映し、Q値を大きく更新します。環境が変化しやすい場合や、迅速に学習する必要がある場合に有効です。  
低い alpha 値 (例: 0.1): エージェントは既存の知識を重視し、Q値をゆっくりと更新します。安定した環境で、過去の経験を重視する場合に有効です。  

# 具体例  
以下に、各パラメータを変更した場合の具体例を示します。

## 探索を重視する場合  
epsilon = 0.9  # 探索率を高くする  
gamma = 0.9    # 将来の報酬を重視する  
alpha = 0.5    # 学習率を中程度にする  
## 既存の知識を重視する場合  
epsilon = 0.1  # 探索率を低くする  
gamma = 0.9    # 将来の報酬を重視する  
alpha = 0.1    # 学習率を低くする  
## 即時の報酬を重視する場合  
epsilon = 0.5  # 探索率を中程度にする  
gamma = 0.1    # 即時の報酬を重視する  
alpha = 0.5    # 学習率を中程度にする  

これらのパラメータを調整することで、エージェントの学習プロセスを制御し、特定のケースに対応することができます。
